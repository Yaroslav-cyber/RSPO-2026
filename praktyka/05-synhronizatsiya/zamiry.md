## Крок 2. Пошук помилки

У програмі було знайдено дві основні проблемні ділянки.

### Проблема 1

```python
vidvantazheno.value = vidvantazheno.value + kilkist
```

Цей рядок складається з декількох окремих дій:

1. прочитати поточне значення;
2. додати `kilkist`;
3. записати нове значення.

Якщо два процеси одночасно читають одне й те саме значення, один результат може бути перезаписаний іншим процесом.

Наприклад, якщо значення дорівнює `100`, один процес може прочитати `100` і підготувати `103`, а інший також прочитає `100` і підготує `102`. Один із результатів буде втрачено.

Це призводить до неправильного значення `vidvantazheno` і порушує **інваріант 2**.

### Проблема 2

```python
if zalyshok.value >= kilkist:
    zalyshok.value = zalyshok.value - kilkist
```

Тут проблема виникає між перевіркою та зміною значення.

Один процес може перевірити, що товару достатньо, але до списання інший процес уже змінить `zalyshok`.

Наприклад:

```text
zalyshok = 2

Процес 1: перевіряє 2 >= 2 → True
Процес 2: списує 2
Процес 1: списує свої 2
```

У результаті залишок може стати від'ємним.

Ця проблема порушує **інваріант 1** і також може вплинути на **інваріант 2**.

### Таблиця проблем

| Рядок коду | Що може статися між діями | Який інваріант ламає |
|---|---|---|
| `vidvantazheno.value = vidvantazheno.value + kilkist` | Інший процес може прочитати старе значення та записати свій результат. Оновлення одного процесу буде втрачено. | Інв. 2 |
| `if zalyshok.value >= kilkist:` + `zalyshok.value = zalyshok.value - kilkist` | Інший процес може змінити запас між перевіркою та списанням. | Інв. 1 та інв. 2 |

## Крок 3. Виправлення

Для виправлення було створено спільний об'єкт блокування:

```python
zamok = mp.Lock()
```

Блокування передається кожному процесу.

Критична частина коду захищається:

```python
with zamok:
    if zalyshok.value >= kilkist:
        zalyshok.value = zalyshok.value - kilkist
        vidvantazheno.value = vidvantazheno.value + kilkist
        moi += kilkist
    else:
        vidmov.value = vidmov.value + 1
```

При цьому `Lock` знаходиться всередині циклу, тому різні процеси все ще можуть паралельно виконувати інші частини програми.

Також було додано локальний лічильник `moi`, який показує, скільки товару відвантажив кожен процес.
