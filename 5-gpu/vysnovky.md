# Висновки

Під час практичної роботи було реалізовано обчислення множини Мандельброта на GPU за допомогою CUDA та Numba. Для зображення 1200×800 час виконання GPU-ядра становив 15.297 мс, а з урахуванням копіювання даних — 17.506 мс, що забезпечило прискорення приблизно у 9.32 раза порівняно з CPU-реалізацією `njit(parallel=True)` у тому самому середовищі Colab. На найменшому зображенні 300×200 копіювання займало 35.9% загального часу, а на найбільшому 3000×2000 — 15.3%. У проведених вимірюваннях GPU був швидшим за CPU навіть для найменшого з трьох зображень, однак для одноразових малих обчислень накладні витрати на запуск ядра та передачу даних мають більший вплив, ніж під час багаторазових обчислень на вже підготовлених даних. Під час перевірки результатів виявлено дві розбіжні точки з 960000; точну причину відмінності CPU та GPU не встановлено, тому потрібне додаткове дослідження чисельних обчислень. Для grid-stride loop найкращий із виміряних результатів становив 8.539 мс при `k = 4`, а подальше збільшення кількості блоків не дало помітного прискорення. GPU не обов'язково буде корисним для невеликих задач із простими обчисленнями, малим обсягом даних або частими передачами між CPU та GPU.
