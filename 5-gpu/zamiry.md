## Практична 07 — GPU і CUDA

**Середовище:** Google Colab, Python 3.13, Numba 0.61.2, відеокарта NVIDIA Tesla T4, 40 SM, warp size 32.

Параметри обчислення: `MAX_ITER = 300`, блок CUDA — `16 × 16` потоків. Для CPU використано `njit(parallel=True)`, для GPU — ядро `mandelbrot_gpu`.

### Порівняння CPU і GPU

| Розмір зображення | CPU `njit(parallel=True)`, мс | GPU, лише ядро, мс | GPU, з копіюванням, мс | Прискорення з копіюванням |
|---|---:|---:|---:|---:|
| 300×200 | 22.373 | 2.183 | 3.407 | ×6.57 |
| 1200×800 | 163.200 | 15.297 | 17.506 | ×9.32 |
| 3000×2000 | 1904.092 | 60.489 | 71.376 | ×26.68 |

Час GPU з копіюванням включає передачу вихідного масиву на пристрій, виконання ядра та копіювання результату назад. Час компіляції Numba не враховувався: перед замірами CPU-функція запускалася для прогріву.

### Частка копіювання

| Розмір зображення | Передача на GPU, мс | Ядро, мс | Копіювання назад, мс | Частка копіювання |
|---|---:|---:|---:|---:|
| 300×200 | 1.006 | 2.183 | 0.218 | 35.9% |
| 1200×800 | 1.196 | 15.297 | 1.013 | 12.6% |
| 3000×2000 | 4.999 | 60.489 | 5.888 | 15.3% |

### Grid-stride loop

Розмір блока — `16 × 16`; кількість SM — 40. Сітка задавалася як `(40 × k, 4)`, де `k` змінювався від 1 до 16.

| k | Сітка блоків | Кількість потоків | Час ядра, мс | Розбіжних пікселів |
|---:|---:|---:|---:|---:|
| 1 | 40×4 | 40960 | 21.531 | 0 |
| 2 | 80×4 | 81920 | 22.547 | 0 |
| 4 | 160×4 | 163840 | 8.539 | 0 |
| 8 | 320×4 | 327680 | 9.182 | 0 |
| 16 | 640×4 | 655360 | 8.771 | 0 |

Найменший виміряний час grid-stride ядра — 8.539 мс при `k = 4`. Подальше збільшення кількості блоків не дало додаткового прискорення в цих вимірюваннях.

### Перевірка результатів

Під час порівняння звичайного GPU-ядра з CPU-реалізацією було виявлено 2 розбіжні пікселі з 960000 для зображення 1200×800. Водночас усі варіанти grid-stride loop дали 0 розбіжних пікселів порівняно зі звичайним GPU-ядром. Причину двох розбіжностей між CPU та GPU остаточно не встановлено.

**Примітка:** результати CPU та GPU в цьому розділі отримані в одному середовищі Google Colab. Попередні результати послідовного виконання на локальному комп'ютері вимірювалися на іншому обладнанні й не є прямим порівнянням продуктивності CPU та GPU.
